# β‑Glucan Inflammatory Effect Analysis
本项目挖掘PubMed文献，探究影响β‑葡聚糖炎症效应的关键因素。
从文献摘要提取实验元数据，人工标注每篇研究的炎症标签（抗炎 / 促炎），使用随机森林模型筛选影响炎症结局的重要变量，并评估模型分类性能。

## 🔍 核心发现
1. 特征重要性：**实验物种、靶器官是排名前两位的预测变量**。人体来源的实验研究更常报道抗炎效果，结肠、肠道是β‑葡聚糖重要作用位点；多糖来源、口服给药的权重相对靠后。
2. 混淆矩阵模型评估：
    - 模型对抗炎样本识别效果较好，抗炎召回率 81.8%
    - 促炎样本召回率仅 11.1%，大量促炎文献被误判为抗炎
    - 主要原因：数据集样本不均衡，抗炎文献数量明显多于促炎文献。
    > 提示：当前模型识别促炎风险的能力有限，后续可以使用样本重采样的方法平衡数据集，优化模型性能。
